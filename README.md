# 🧮 Калькулятор (ДЗ №17)

Простой калькулятор на чистом JS.  
Поддерживает: сложение, вычитание, умножение, деление.

## 🚀 Запуск
1. Откройте `index.html` в любом современном браузере.
2. Введите два числа и нажмите кнопку операции.

## 📦 Структура
- `index.html` — разметка
- `style.css` — стили
- `app.js` — логика (делегирование, валидация, защита от деления на 0)
